What is a Team Grid?

そもそも、Team Grid って何？

Team Grid は、Gallup公式 CliftonStrengths Team Grid に基づいたチーム可視化の手法。
メンバーひとりひとりの強みを、「チーム全体としての色」 に重ね直して見るためのフレームワークです。

ひとことで言うと

メンバー全員のTOP5資質を、ストレングスの4領域（🟣実行・🟠影響・🔵人間関係・🟢戦略）の「マス目」に並べて配置するチーム俯瞰マップ。

個人の資質を読むだけでは見えない「チームの形」を、1枚で見えるようにする道具です。

何が見えるの？

マス目に 名前が並ぶ場所＝チームの強み。空いてるマス＝助け合いが必要な領域。
さらに、同じ資質が複数人にある場所＝「共通燃料」 として、チームが自然に響き合う軸が見えてきます。

どうやって読むの？

1. まず マス目の埋まり方 を眺める → どの領域に偏りがある？
2. 次に 空いてるマス を確認 → 誰がここを意識的に補ってる？
3. 最後に 重なる資質 を探す → ここがチームの "響き合う共通言語"。

何のために使うの？

「誰が何を担い、どこを助け合うか」を、感覚じゃなく構造で見るため。

役割分担／新メンバー採用／困った時の頼り先／お互いへのリスペクトの根拠 — ぜんぶこれで見えるようになる から、不要なズレや衝突が減ります🌸

大事な前提： Team Grid は「優劣」を測るものじゃありません。
4領域のどれが「上」とか「下」もありません。
「うちのチームは、こういう色なんだね」 を、みんなで共有するための地図です。

Common fuels — 4人で響き合う軸

4人が揃ったとき、必ず効く「共通燃料」。

同じ資質が複数人のTOP5入りしてる＝その軸でチームが自然に共鳴できる。

共感性 🌷おけもん②・🌻なっつん④・🌿くう②（3人がTOP5入り）
→ 「気持ちを汲む」が共通言語。感情を切り捨てない文化が自然に走る。
最上志向 🌷おけもん⑤・🌻なっつん①・🌿くう⑧（3人）
→ 「もっと良くしたい」品質ベクトルが揃う。妥協で止まれないチーム。
ポジティブ 🌷おけもん⑨・🌻なっつん③・🌿くう④（3人）
→ 明るく挑戦的な空気が3人で増幅。場の温度を作る燃料。
学習欲 🌿くう⑤・🌸りえ④（2人がTOP5）
→ 新しいものを一緒に学ぶペア。仕組み・ツールの導入はこの2人が起点。
調和性 🌷おけもん①・🌿くう⑥・🌸りえ⑦（3人）
→ 「対立より共通項を探す」が3人ベース。場が荒れにくい構造。
未来志向 🌿くう③・🌷おけもん⑩（2人）
→ 未来の絵を一緒に描けるペア。長期方針を語る時はこの2人軸。

Insights — 4つの発見

このグリッドから見えてくる4つのこと。

強み① 人間関係構築力が異常に厚い

🌷おけもん4資質・🌻なっつん4資質・🌿くう5資質。4人の合計で13資質が人間関係TOP10入り。

→ チーム内の 結束・対人ケア・空気感の柔らかさは無双の強み。共感性は3人共通TOP5、調和性も3人共通TOP10。「誰かが落ちそうな時、必ず誰かが気づく」構造。

注意① 実行力＝りえ一人で背負ってる

実行力TOP5に入ってるのは 🌸りえだけ（回復志向①・慎重さ③・規律性⑤）。
おけもんは3資質あるけど中位、なっつん・くうはゼロ。

→ りえが抜けると、チーム全体の継続力・規律・着地点が一気に弱くなる。
意識的にりえへの感謝とリスペクトを言葉にすること／なっつんとくうも 「規律性は意識的に補う領域」 として向き合う。

強み② 戦略思考も2人がしっかり

🌿くうが3資質（未来志向③・学習欲⑤・収集心⑩）、🌸りえも3資質（分析思考②・学習欲④・内省⑧）。

→ くうが「未来を描く」、りえが「分析して整える」のペアで、長期方針も足元の精度も両方カバーできる。学習欲が2人共通TOP5＝新しい仕組みを一緒に吸収。

注意② 影響力は「ペア依存」

影響力TOP5に入ってるのは 🌻なっつん（最上志向①）だけ。
おけもん⑤・くう⑧は中位、りえは自我⑨のみ。

→ 対外発信・代表挨拶・営業の場はなっつんに集中しやすい構造。なっつんが疲弊しないよう、おけもんのコミュ⑦＋最上志向⑤で意識的にサポート。

Synergy patterns — 4人で動く時のフォーメーション

場面ごとの、4人フォーメーション例。

新メンバーをirodoriに迎える時

→ 「描く → 検証 → 合意 → 決断」の流れがそのまま4人で組める。

トラブル発生時

🌸りえ（回復志向①）＝原因究明・修復／🌷おけもん（共感性②）＝関係者の感情ケア／🌻なっつん（適応性②）＝即座に方針転換／🌿くう（共感性②＋ポジティブ④）＝場の温度を保つ。
